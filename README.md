## Projects

---

**NexaSoul**
Local-first AI communication training platform where agents simulate realistic human emotional states using Ollama LLM. Features an emotional state engine that dynamically influences agent responses based on conversation history, memory-based bias, and contextual triggers — across 5 training modes including job interviews and conflict resolution. Built with Node.js, WebSocket, SQLite, and React/TypeScript.

https://github.com/Vignesh5432/NexaSoul-AI

---

**AI Orchestration Engine**
API-first AI decision engine that intelligently routes tasks across multiple LLM providers based on risk, cost, and latency constraints. Implements 4 execution strategies — single-model, parallel consensus, verify-then-return, and fallback — using deterministic rule-based logic. Every decision outputs explainable reasoning detailing why a specific model and strategy was selected. Validated with real API calls across HuggingFace and Groq.

https://github.com/Vignesh5432/AI_ORCHESTRATOR

---

**MisInfo Intelligence**
AI-assisted misinformation risk analysis system with FastAPI backend and Streamlit analyst dashboard. Built as an explainable decision-support tool — not a binary fake/real classifier. Features a non-binary risk scoring engine (0–100) combining claim uncertainty, manipulation signal detection, narrative coordination patterns, and source reliability with weighted fusion logic. Integrates HuggingFace Transformers, spaCy, and NetworkX for semantic narrative graph clustering.

https://github.com/Vignesh5432/MISINFO_INTELLIGENCE

---

**Industrial Worker Safety Monitor**
Full-stack industrial worker safety monitoring system simulating AI-powered wearable sensors. Built a deterministic multi-parameter fusion engine combining health vitals, gas levels, and fatigue with weighted risk scoring across 4 zone-sensitive industrial environments. Dual admin/worker dashboards with real-time alert flows, two-way messaging, unconscious detection via inactivity timeout, and daily CSV report generation. Includes unit tests for the decision engine and alert cooldown logic.

https://github.com/Vignesh5432/SMART_SAFETY_ASSSITANT

**Voxign**
Real-time sign language communication bridge connecting deaf and hearing users via WebSocket architecture. Integrates MediaPipe Hands for camera-based gesture recognition with a confidence scoring system. Features dual-interface design with separate optimised dashboards for hearing and deaf users, Socket.IO session management with unique session codes, and an intelligent phrase matching engine with letter-by-letter spelling fallback.

https://github.com/Vignesh5432/VOXIGN_AI

Backend handles real-time telemetry routing, medication scheduling, and emergency escalation logic with full test coverage.
